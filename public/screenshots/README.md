# Home Money Screenshots Directory

This directory stores real mobile screenshots displayed on the marketing website.

## Required / Recommended Screenshot Files

For best visual quality, capture portrait screenshots from an Android device (e.g. 1080x2400 or similar aspect ratio) and name them as follows:

| Filename | Screen Content |
| :--- | :--- |
| `01-dashboard.png` | Main Home screen showing monthly balance, cash flow, and recent expenses |
| `02-add-expense.png` | Expense entry form showing amount, category picker, and payment method |
| `03-multi-item.png` | Multi-item receipt splitting across different categories |
| `04-analytics.png` | Analytics screen with category breakdown, spend averages, and trends |
| `05-bills.png` | Bills screen showing recurring obligations and paid/due-soon indicators |
| `06-budgets.png` | Budgets screen with monthly & category spending progress bars |
| `07-pdf-report.png` | Preview of the generated print-ready monthly financial PDF report |

## Replacement Instructions

1. Take screenshots on your Android phone running the Home Money app.
2. Save them into this folder (`home-money-website/public/screenshots/`) using the filenames above.
3. The website will automatically render your real screenshots inside the sleek mobile device frame components!
